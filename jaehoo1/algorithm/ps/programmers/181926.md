분기처리
```python
def solution(n: int, control: str) -> int:
    for c in control:
        if c == 'w':
            n += 1
        elif c == 's':
            n -= 1
        elif c == 'd':
            n += 10
        elif c == 'a':
            n -= 10
    return n
```
